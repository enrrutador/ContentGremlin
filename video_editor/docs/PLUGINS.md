# Sistema de Plugins

Manifiesto JSON por plugin, validado contra `src/plugins/manifest.schema.json`.

Campos clave: id, name, version, category, type, params, ffmpeg, license.

Catálogo central: `plugins/catalog.json` con 200 módulos planificados.

Ejecución local únicamente. No se suben vídeos a servicios externos.

Categorías y cantidades definidas en roadmap.
